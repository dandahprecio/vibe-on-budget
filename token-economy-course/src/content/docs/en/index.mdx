Learn how to save tokens and AI Credits when coding with GitHub Copilot. This course covers everything from the basics of usage-based billing to advanced techniques for prompt optimization, project setup, and agent hygiene.

## Prerequisites

- A GitHub Copilot subscription (Free, Pro, or Enterprise)
- VS Code with GitHub Copilot extension installed
- Basic familiarity with the Copilot chat interface

## How to Use This Course

Each module is self-contained and takes about 8–12 minutes to read. Modules build on each other but can also be consumed independently. Look out for **deep dive** sections if you want the full technical details.
