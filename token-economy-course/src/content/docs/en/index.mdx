# Token Economy for Vibe Coding

Learn to complete coding tasks while keeping quality high, your workflow understandable, and token and AI Credit usage reasonable.

You do not need prior GitHub Copilot experience. The course starts with understanding usage, then gradually builds a practical workflow that you can follow and improve.

## To read

You need:

- basic programming experience
- the ability to read and change code in a project

You do not need to have used GitHub Copilot before. The course introduces concepts and workflows when you need them.

## To try

If you want to do the exercises, you also need:

- a stable VS Code installation
- access to GitHub Copilot
- a safe working copy of a project where you can experiment without risking the original

The exercises are optional. You can read the entire course without following them step by step.

## How the course is structured

The main track follows the order below. Start with usage, try a controlled workflow, and then build on it with better prompts, sessions, project instructions, and your own routine.

Each module contains what you need for the next step. You can skip the optional exercises. **Deep dives** provide additional technical background, but you can also skip them when you want to stay focused on the workflow.
