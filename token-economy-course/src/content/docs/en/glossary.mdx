title: Glossary
description: Key terms and concepts for the Token Economy course
---

### Acceptance criteria

Conditions that describe when a task counts as complete. Example: a test must pass and a specific file must be updated. First covered in [Give a clear assignment and the right context](/vibe-on-budget/en/prompts-and-context).

### Agent

A workflow in which the model can plan, use tools, and carry out several steps in a task. Example: the agent investigates a codebase, changes a file, and runs a test. First covered in [Limit the agent's work](/vibe-on-budget/en/agents-and-tools).

### Agent mode

A mode in which Copilot can use tools and continue through several work steps in the same task. Example: agent mode can read relevant files, suggest a change, and verify it. First covered in [Choose a workflow and manage the session](/vibe-on-budget/en/sessions-and-models).

### AI Credit (credit)

A unit GitHub Copilot uses to describe usage in some plans and models. Example: an interaction can be recorded as a number of AI Credits depending on the model and usage. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Working copy

A separate or recoverable copy of a project where you can try a change. Example: create a branch or copy before letting Copilot change code. First covered in [Make a first, controlled attempt](/vibe-on-budget/en/first-task).

### Effort versus result quality

A comparison between the time and attention a task requires and how well the result meets its requirements. Example: two solutions can produce the same test result but require different amounts of review. First covered in [Compare and build your workflow](/vibe-on-budget/en/working-routine).

### Baseline

A documented starting point for a task, such as usage, time, rework, and quality. Example: write down how a representative task works before changing your process. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Cache

Stored parts of previously processed context that can be reused when a later request matches. Example: a stable prompt prefix can remain in a cache between requests. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Caching

The process of saving and reusing context or other processed content. Example: prompt caching can reuse the same instructions when the prefix is unchanged. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Input token

A token in the material sent to the model, such as a prompt, file content, or history. Example: the text in an attached code file becomes input tokens when it is sent in a request. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Instruction file (`.github/copilot-instructions.md`, `AGENTS.md`)

A file that describes rules or project context for an AI tool. Example: the file can state which tests to run or which directories must not be changed. First covered in [Save what works in the project](/vibe-on-budget/en/project-instructions).

### Compression

Making context or a response shorter by removing repetition while retaining relevant information. Example: a long session history can be summarized before work continues. First covered in [Choose a workflow and manage the session](/vibe-on-budget/en/sessions-and-models).

### Context

The combined material a model receives for a request, such as the prompt, files, instructions, and session history. Example: the same prompt can produce different results depending on which code is in context. First covered in [Give a clear assignment and the right context](/vibe-on-budget/en/prompts-and-context).

### Context window

The amount of tokens a model can handle within a request or work step. Example: when a session fills the window, older context must be summarized, removed, or replaced. First covered in [Give a clear assignment and the right context](/vibe-on-budget/en/prompts-and-context).

### MCP (Model Context Protocol)

A protocol for connecting AI models to external tools and data sources through MCP servers. Example: an MCP server can offer a tool that reads information from another system. First covered in [Limit the agent's work](/vibe-on-budget/en/agents-and-tools).

### Model

The language model that interprets context and generates a response or action. Example: the same task can produce different answers when you change the model. First covered in [Choose a workflow and manage the session](/vibe-on-budget/en/sessions-and-models).

### Output token

A token in the model's generated response, such as code, text, or a tool call. Example: a long explanation and a large code patch contain more output tokens than a short summary. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Prompt

The instruction or question you send to the model, together with any stated constraints and desired result. Example: a prompt can specify the goal, relevant files, acceptance criteria, and response format. First covered in [Give a clear assignment and the right context](/vibe-on-budget/en/prompts-and-context).

### Session

A continuous work dialogue in which previous messages and results can be included in later steps. Example: a session can begin with investigation and continue with a change and verification. First covered in [Choose a workflow and manage the session](/vibe-on-budget/en/sessions-and-models).

### Token

A text unit the model uses when processing language and code. A token can be part of input, output, or reused context. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Task cost

The combined resources needed to complete a task, such as tokens, AI Credits, waiting, review, and rework. Example: a short prompt can still lead to high task cost if the task requires many agent steps. First covered in [Understand usage](/vibe-on-budget/en/understand-usage).

### Tool

A function the model can call to read, change, search, or verify something outside the text response itself. Example: a tool can read a file or run a test. First covered in [Limit the agent's work](/vibe-on-budget/en/agents-and-tools).
