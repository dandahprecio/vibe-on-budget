## Förkunskaper

- Ett GitHub Copilot-abonnemang (Free, Pro eller Enterprise)
- VS Code med GitHub Copilot-tillägget installerat
- Grundläggande kännedom om Copilot-chattgränssnittet

## Hur du använder kursen

Varje modul är fristående och tar cirka 8–12 minuter att läsa. Modulerna bygger på varandra men kan också läsas oberoende. Håll utkik efter **fördjupningar** om du vill ha alla tekniska detaljer.
