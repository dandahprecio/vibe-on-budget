## Förkunskaper

- Ett GitHub Copilot-abonnemang (Free, Pro eller Enterprise)
- VS Code med GitHub Copilot-tillägget installerat
- Grundläggande kännedom om Copilot chatt-gränssnittet

## Hur du använder kursen

Varje modul är fristående och tar cirka 5–10 minuter att läsa. Modulerna bygger på varandra men kan även läsas oberoende. Håll utkik efter **fördjupningsavsnitt** om du vill ha alla tekniska detaljer.
