# Tokenekonomi för Vibe Coding

Lär dig att slutföra koduppgifter med bibehållen kvalitet, ett begripligt arbetssätt och en rimlig förbrukning av tokens och AI Credits.

Du behöver inte kunna GitHub Copilot i förväg. Kursen börjar med hur du kan förstå förbrukningen och bygger sedan stegvis upp en arbetsrutin som är lätt att följa och förbättra.

## För att läsa

Du behöver:

- grundläggande programmeringsvana
- kunna läsa och ändra kod i ett projekt

Du behöver inte ha använt GitHub Copilot tidigare. Begrepp och arbetssätt introduceras när de behövs.

## För att prova

Om du vill göra övningarna behöver du dessutom:

- en stabil installation av VS Code
- tillgång till GitHub Copilot
- en säker arbetskopia av ett eget projekt där du kan prova utan att riskera originalet

Övningarna är frivilliga. Du kan läsa hela kursen utan att följa dem steg för steg.

## Så är kursen upplagd

Huvudspåret går i ordningen nedan. Börja med förbrukningen, prova sedan ett avgränsat arbetssätt och bygg därefter vidare mot bättre promptar, sessioner, projektinstruktioner och en egen rutin.

Varje modul innehåller det som behövs för nästa steg. Övningar är valfria och kan hoppas över. **Fördjupningar** ger mer teknisk bakgrund, men kan också hoppas över när du vill hålla fokus på arbetssättet.
