# Snabba vinster

Sex saker du kan göra **imorgon bitti** för att börja spara tokens. Var och en tar 5 minuter eller mindre och har omedelbar effekt.
Det här är engångskonfigurationer. För den löpande färdigheten att skriva effektiva prompter, se [Modul 5](/vibe-on-budget/sv/05-cheaper-prompts).[^m4-1]

:::note[Besparingsuppskattningar]
Besparingsuppskattningarna är författarens beräkningar baserade på tokenmekanik (förhållandet mellan input- och output-tokens, cache-ekonomi och modellpriser). Faktiska besparingar varierar beroende på projektets storlek, modell och arbetsflöde. Externa riktmärken anges där sådana finns.[^m4-2]
:::

---

*(Se [Ordlista](/vibe-on-budget/sv/glossary) för definitioner av BPE, unified diff och .copilotignore.)*

## 1. Lägg till en Code-Only-instruktion 🟢

**Problemet:** Varje chatsvar inkluderar artighetsfraser, förklaringar och markdown-omslag kring oförändrad kod. Output-tokens kostar 5x input — denna svullnad är dyr.[^m4-2][^m4-3]

**Åtgärden:** Lägg till detta i din `.github/copilot-instructions.md` (en fil i `.github/`-mappen i ditt projekts rot — Copilot läser den vid varje förfrågan):

```
# Output-format
- Returnera endast kodblock. Ta bort all text, hälsningar, förklaringar.
- Ingen markdown-text utanför kodblocket.
- Ersätt oförändrad kod med: // ... existing code ...
```

**Besparingen:** 50–70% minskning av output-tokens per svar.[^m4-2]

---

## 2. Rensa din chattråd regelbundet 🟢

**Problemet:** Varje meddelande i en pågående tråd skickar hela konversationshistoriken som input-tokens.

**Åtgärden:**
- **Samma uppgift, 10+ steg?** Använd [`/compact`](https://code.visualstudio.com/docs/agents/run/sessions/manage-sessions#_compact-conversation-context) för att sammanfatta äldre delar.
- **Uppgiften klar?** Starta ny chatt med `Ctrl+N` (Windows/Linux) eller `⌘N` (Mac).

Se [Modul 2](/vibe-on-budget/sv/02-context-model) för en komplett beslutsmatris: när du ska stanna i sessionen, när du ska rensa, och när du ska förgrena.

**Besparingen:** 40–60% minskning av input-tokens för sessioner med ackumulerad historik.[^m4-4]

---

## 3. Stäng onödiga editorflikar 🟢

**Problemet:** Copilot läser dina öppna editorflikar som kontext. Att ha 15 filer öppna när du frågar om en funktion skickar 14 irrelevanta filer som input-tokens med varje förfrågan.[^m4-5]

**Åtgärden:**

1. Innan du ställer en fråga, stäng filer du inte arbetar med
2. Håll bara filen/filerna direkt relevanta för din uppgift öppna
3. Använd `#file:filnamn.mjs` för att explicit referera till en fil — då slipper du ha den öppen som flik[^m4-5]

**Besparingen:** 20–40% minskning av input-tokens per förfrågan. Än viktigare: du får **bättre svar** eftersom modellen ser mindre brus.[^m4-4]

---

## 4. Skapa en [`.copilotignore`](https://code.visualstudio.com/docs/agents/optimize-usage-guide#_exclude-files-with-copilotignore)-fil 🟢

**Problemet:** Copilot skannar din arbetsyta efter kontext. Byggartefakter, testfixturer, mockdata, CSV-filer och `node_modules` inkluderas alla som potentiell kontext — trots att de aldrig är användbara för kodgenerering.[^m4-5][^m4-6]

**Åtgärden:** Skapa `.copilotignore` i projektroten:

```
# .copilotignore
dist/
build/
node_modules/
tests/mock-data/
*.svg
*.csv
*.json
package-lock.json
```

**Besparingen:** 20–40% mindre input-tokenförbrukning. Bonus: snabbare svarstider.[^m4-4]

:::caution[Inte en säkerhetsgräns]
[`.copilotignore`](https://code.visualstudio.com/docs/agents/optimize-usage-guide#_exclude-files-with-copilotignore) är ett verktyg för att spara tokens, inte en säkerhetsåtgärd. Anta inte att det förhindrar data från att lämna din maskin.[^m4-6]
:::

---

## 5. Använd Auto modellval 🟢

**Problemet:** Varje chattförfrågan använder som standard samma modell. Att använda Claude Opus (output: $75/M tokens) för en regex-genereringsfråga är som att hyra en lastbil för att flytta en kaffekopp.[^m4-3]

**Åtgärden:**

För en underhållsfri standard, använd **[auto modellval](https://code.visualstudio.com/docs/agent-customization/language-models)**. VS Code dirigerar automatiskt varje förfrågan till en effektiv modell baserat på uppgiftens komplexitet, modellens hälsa och tillgänglighet.[^m4-7]

Som ett avancerat alternativ kan du manuellt välja modell. Använd lätta modeller (Haiku eller GPT-mini) för:
- Regex-mönster
- Generering av dokumentationssträngar
- Enkel kodformatering
- Strängmanipulering
- Generering av boilerplate

Använd premiummodeller (Sonnet, Opus) endast för:
- Arkitekturbeslut
- Komplex refaktorering
- Ändringar över flera filer
- Säkerhetsgranskningar

**Besparingen:** 5–15x kostnadsminskning per förfrågan (beräknat utifrån pris per modell). En enkel fråga kostar $0,0001 på Haiku vs $0,0015 på Sonnet — och du märker förmodligen inte kvalitetsskillnaden för rutinuppgifter.[^m4-3][^m4-7]

## 6. Tvinga unified diff-utdata 🟢

**Problemet:** LLM:er returnerar ofta hela filen när du ber om redigeringar — även om bara några få rader ändrats. Detta är "lathetsproblemet": modellen tycker det är enklare att regenerera en hel fil än att beräkna en diff. Resultatet är massivt slöseri med output-tokens, eftersom varje oförändrad rad skickas tillbaka som output-tokens till 5x input-kostnad.[^m4-8]

**Åtgärden:** Lägg till denna metaprompt i din `.github/copilot-instructions.md` eller i början av relevanta sessioner:

```
Use unified diff. Only changed lines +/- with 3 context lines. No full file output.
```

Detta tvingar modellen att endast returnera de rader som ändrats, med några få raders kontext runt varje ändring för läsbarhet.

**Besparingen:** 70–80% minskning av output-tokens vid kodredigeringsuppgifter.[^m4-8]

:::note[Maximala besparingar]
Kombinera med Code-Only-instruktionerna från Quick Win #1 för maximala besparingar.[^m4-2][^m4-8]
:::

## Övning 🟢

Använd din representativa uppgift och baslinje från Modul 3. Efter varje övning, kör om uppgiften och jämför credits, tokens och kvalitet mot din baslinje.

1. Lägg till instruktionen om endast kod i `.github/copilot-instructions.md` (Snabb vinst #1). Skicka samma prompt som du använde för baslinjen i Modul 3. Jämför creditkostnaden.[^m4-2][^m4-9]
2. Skapa en `.copilotignore`-fil i ditt aktuella projekt (Snabb vinst #4). Använd mallen från den här modulen.[^m4-6]
3. Kontrollera modellväljaren. Är den inställd på Auto? Om inte, byt till Auto nu. (Snabb vinst #5)[^m4-7]

## Viktiga slutsatser 🟢

- **Code-only-instruktioner** tar bort text och omslag och sparar **50–70% output-tokens**[^m4-2]
- **`/compact` och nya chattrådar** hindrar gammal historik från att byggas på och sparar **40–60% input-tokens** i längre sessioner[^m4-1][^m4-4]
- **Färre öppna flikar** håller den automatiska kontexten fokuserad och sparar **20–40% input-tokens** per förfrågan[^m4-4][^m4-5]
- En **`.copilotignore`-fil** tar bort irrelevant arbetsytekontext och sparar **20–40% input-tokens**[^m4-4][^m4-6]
- **Lätta modeller** minskar kostnaden för rutinuppgifter med **5–15x per förfrågan**[^m4-7]
- **Unified diff-utdata** stoppar regenerering av hela filer och sparar **70–80% output-tokens** vid redigeringsuppgifter[^m4-8]
